# MASOOM — Pre-Launch Concept Sandbox

MASOOM is a private, unified digital ecosystem designed specifically for women's healthcare, education, and emotional support. Currently, women have to navigate scattered platforms for cycle logs, doctor consults, vaccine schedules, and sensitive health chats. MASOOM brings all of these experiences under one safe, confidential roof.

This repository hosts the **Premium Pre-Launch Homepage Concept** designed for the Acdyon frontend track challenge.

---

## 🌸 Core Sandbox Features (Interactive Previews)

We have built six distinct interactive preview modules so visitors can experience MASOOM's planned capabilities first-hand:

1.  **Doctor Consultations:** Interactive appointment widget featuring real-time available time-slots and mock video booking confirmation.
2.  **Vaccination Planner:** A wobbly checked checklist tracker to schedule and log key vaccinations (like HPV) across life stages.
3.  **AI Health Assistant:** Simulated voice-note chat screen representing our motherly AI assistant, featuring quick-action guidance loops and a recording indicator.
4.  **Sensitive Health Support:** A private "unlock pattern" workspace that lets users securely drill down into confidential reproductive and sexual health topics.
5.  **Health Comics Section:** A modular comic viewer strip showing panel-based, engaging healthcare comics (such as hormone level graphs) designed for younger audiences.
6.  **Medicine Recommendations & Guidance:** A diagnostic guide card list providing safety dosages, purposes, and descriptions for over-the-counter medications.

## 🛠️ Technology Stack & UX Engineering

*   **Frontend Library:** React.js (Vite environment)
*   **Style Framework:** Tailwind CSS v4 (using CSS custom properties mapping for instant variables painting)
*   **Motion Library:** Framer Motion (leveraged strictly for card scroll reveals to maintain performance)
*   **UX Animations:** Curated native GPU-accelerated CSS keyframe transitions for tactile hover lifts, button shrinks, and indicator pulses.
*   **Responsive Integrity:** Strict 100% viewport compliance across mobile (390px) and desktop (1440px) breakpoints with zero horizontal scroll layout leakage.
